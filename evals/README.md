# Evals

The gold tasks and the scoring for the query language and the agent. The tasks come from the study of what researchers actually asked of NILS v0's agent (question families, scored trajectories), rewritten so that no task carries a subject, a study or a path from a real registry. The engine's query language is judged by whether every gold task can be expressed in it and answered correctly on a synthetic registry; the agent (D23) is judged on the same tasks, on a fixed harness, in a six-week pilot.
